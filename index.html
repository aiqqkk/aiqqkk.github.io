Model Y 记录本

为本人拥有的 Model Y 开发用车记录工具，计划记录行程、充电和电量变化，帮助本人查看与分析用车情况。

当前已完成离线模拟验证，尚未接入真实车辆。本网站是项目介绍页，不提供车辆登录、远程控制或商业服务。

计划实现的功能

  • 查看每次行程的起止时间、里程和轨迹。
  • 查看每次充电的时长、电量及费用记录。
  • 区分实测、估算和缺失数据，方便核对结果。

当前数据处理说明

此静态介绍页没有登录或信息提交表单，也没有主动读取 Tesla 账户、车辆位置、授权令牌的程序。

后续真实车辆接入仅用于本人授权的车辆。实际授权流程与数据保存方式完成后，将更新相应说明。

如果本页面通过 GitHub Pages 发布，托管平台会处理访问日志，详情见 GitHub 隐私声明。
